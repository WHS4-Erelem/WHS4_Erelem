# WHS4_Erelem

WHS4_Erelem은 화이트햇 스쿨 4기 팀 프로젝트 **에레렘**의 프로젝트 자료를 정리한 저장소입니다.

본 저장소에는 프로젝트 수행 과정에서 작성된 킥오프 보고서, 수행계획서, 격주보고서, 중간발표 자료, 주차별 개인 산출물 등이 포함되어 있습니다.
